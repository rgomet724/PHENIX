Comptes synchronisés avec PHENIX

ARGOS utilise directement les identifiants et mots de passe PHENIX.

Pour créer, modifier ou supprimer un compte, faites l’opération dans PHENIX. Le changement est pris en compte automatiquement par ARGOS, sans recopier le mot de passe.

Rôles : admin PHENIX → administrateur ARGOS ; superviseur/opérateur → utilisateur ARGOS ; dashboard → accès ARGOS désactivé.
